# Conteo Inventario / Almacén de Suministro
Práctica Abap Rap - Conteo de Inventario - Almacén de Suministro

---
Parte de las Prácticas de Restful Application Programming Model.
Módulo de Conteo de Inventario Cíclicos y Generales del Almacén de Suministro 
del Centro de Distribución XYZ.

****Almacén de Suministro:****  Inventario de todo el material, herramientas, mercancías, materia prima
que son utilizado para uso interno del centro de distribución, bien sea para uso de personal, uso logístico,
uso administrativo, uso operacional. ***** NO PARA USO DE PRODUCCIÓN ****

---
En ésta práctica el enfoque es el uso de COMPOSITION Y ASOCIATION para las relaciones entre tablas padres e hijas
( Maestro y Detalle ) además del Behavior Definition asociado y el uso de Draft.
